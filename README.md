# Dhruva Patel — Personal Portfolio

A custom-coded, responsive portfolio for the Personal Portfolio Website assignment.

## Run locally

Open `index.html` in a browser. No installation, build step, dependencies or API keys are required.

## Design

The concept connects data science with business decisions: an editorial layout, warm neutral background, ink-blue type, terracotta accents and a conceptual data-to-insight sketch. Inline SVG illustrations represent the project areas; they are not screenshots or measured results. Project filters and expandable project notes work with vanilla JavaScript.

## Publish for free with GitHub Pages

1. Sign in to https://github.com and create a new **public** repository named `dhruva-portfolio`.
2. Extract this ZIP. Upload `index.html`, `README.md`, `.nojekyll` and `SUBMISSION.md` to the repository root using **Add file → Upload files**. Commit them to `main`.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**. Save.
6. Wait for GitHub to display the deployed URL. Expected URL for this username and repository name: https://dhruva2006.github.io/dhruva-portfolio/
7. Open the live URL and repository URL in an incognito window before submitting. Check both on a phone.

If the GitHub account or repository name differs, use the actual URL GitHub displays.

## Update

Edit the text in `index.html` and commit the changed file. GitHub Pages redeploys after the commit. Filters are controlled by `data-category` on projects and `data-filter` on buttons. There is no contact form or backend; the contact link opens the GitHub profile.
